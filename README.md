# 暮らしの見通し

家計の記録と、リタイアまでの見通しを1枚のHTMLで扱う道具です。

- 通帳CSV／カード明細CSVの取り込み
- 月次の記録と、年ごとの実績
- 資産・負債・純資産の推移（実績＋予測）
- 前提を変えたときの比較

## 使い方

`index.html` をブラウザで開くだけです。数字はすべて空なので、
「前提」タブで自分の数字を入れてから使い始めてください。

## データの扱い

入力した内容は**ブラウザのローカルストレージにのみ保存**され、
どこにも送信されません。サーバーもデータベースもありません。

そのため、ブラウザのデータを消すと記録も消えます。
「前提」タブから定期的にファイルへ書き出してください。

なお `file://` で開くとローカルストレージが使えない場合があります。
その場合は `https://` で配信するか、書き出しと読み込みで運用してください。
